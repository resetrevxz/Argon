# Argon

Private release repository for the Argon Windows game library.

Argon brings verified local game installations into a single library. No Argon account is required. Steam, Epic, Riot and other launchers retain responsibility for authentication, entitlement, updates and anti-cheat.

Installed Windows builds use NSIS upgrades with a stable application identity. Release assets include the installer, blockmap and latest.yml metadata. Private release checks require authorized GitHub access on the device; no credentials are embedded in builds.

Unsigned builds may be blocked by Windows application-control policy. Packaging or update support does not bypass that policy.
